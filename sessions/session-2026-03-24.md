## Something new I learned:
- Real applied examples of triggers. 
- :NEW.column is to refer to the new value that the column will have
- :OLD.column is to refer to the value that the row had before
- SYSTIMESTAMP is for getting the current date
- USER is for getting the current user logged in.

A trigger is automatically executed by the database when a DML operation occurs. In a BEFORE trigger, the code runs before the operation is executed and can modify or validate the data. If an error is raised, the operation is canceled. If everything runs successfully, then the database proceeds to execute the original query. In an AFTER trigger, the operation is executed first, and then the trigger runs, typically for logging or auditing purposes.
